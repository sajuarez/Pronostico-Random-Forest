# Algoritmo Random Forest para Predicción de Contaminantes Atmosféricos

**Algoritmo:**
- Random Forest Regressor

**Bibliotecas principales:**
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

---

## Variables utilizadas

El modelo utiliza información relacionada con:

- Concentraciones históricas de contaminantes.
- Variables meteorológicas.
- Variables temporales (día, mes, semana, etc.).

---

## Evaluación del modelo

El desempeño del modelo fue evaluado mediante:

- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- R² (Coeficiente de determinación)
